# Getting Started

The npm package is not published yet. Until the Phase 10 release, install from a clone of the repository:

```sh
git clone <repository-url>
cd typescope
npm install
npm run build
```

## Requirements

- Node.js 22.18 or newer.

## Running from source

```sh
node dist/cli/index.js
```

The CLI implementation lands in Phase 2; until then the binary prints a not-implemented notice.
